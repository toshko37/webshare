1. **Работещото не се чупи.** Този сървър е и източник на beta канала. Всяка фаза завършва с тестове преди следващата.

### Намерено по пътя

- **`share.php` търсеше линка само по име на файла.** „New ID“ и „Revoke“ можеха да засегнат линка на файл със същото име в чужда папка. `regenerate` и `revoke` не проверяваха достъпа. Сега търсенето е по папка и име, с проверка на достъпа при всяко действие.
- **Инсталаторите бяха със стари списъци.** От тях липсваха `upload-guard.php`, `error-page.php`, `auth-guard.php`, `ui-kit.*` и `robots.txt`, а `get-webshare.sh` пропускаше и `login.php` и `logout.php`. Нова инсталация на 3.7.x би спряла с фатална грешка.
- **Beta каналът не може да обновява PHP файлове.** Dev сървърът изпълнява PHP, вместо да връща кода, така че live update получава HTML. `index.php` би бил презаписан със страницата за вход. Добавена е защита: обновяването спира, ако PHP файл не започва с `<?php` (D-022). След това beta каналът е премахнат изцяло и обновяването е само от GitHub (D-023).

**Покрити записи (I4):**
- **Атомарни обновявания.**

  - Метаданните на файловете: качване, изтриване, преименуване и синхронизация.
  - Потребителите: добавяне, парола, роля, изтриване.
  - Проверката на API ключ: `last_used` и научаване на IP.
  - Метаданните за криптирането.
  - Броячът на прегледите на споделена папка.
- **Lock от зареждането до записа.**
  - Линковете в `share.php`.
  - Преименуване, изтриване и преместване на файл в `index.php`.

  - Почистването на изтеклите чатове.
