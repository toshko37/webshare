# Прегледи на линкове и ZIP във фонов режим (F7)

## Open Graph

| | |
|---|---|
| Код | `src/link-preview.php`, `src/og-image.png` (създадена с `tools/make-og-image.php`) |
| Настройка | Settings → Public Access → Link previews (включено по подразбиране) |
| Тест | `php tests/link-preview-unit.php`, 12 проверки, плюс проверка на живо с User-Agent на Viber и Facebook |

| Линк | Какво показва прегледът |
|---|---|
| Файл `/p?t=…` | Име, размер и срок на линка. Ботът получава само картата, а не файла, и сваляне не се отчита. |
| Папка `/f/…` | Име и брой файлове. При защитена с парола папка: само „Защитена папка“. |
| Чат `/t/…` | Само „Чат в WebShare“, никога съдържанието. |
| Настройката е изключена | Само „WebShare“ |

Прегледите на ботовете не се броят като посещения.

## ZIP на споделена папка

- **Как работи.** „Изтегли всички“ стартира задача, която създава архива след отговора на заявката. Страницата показва процент и сваля архива, когато е готов. Без JavaScript старият линк също минава през задачата.
- **Къде стоят архивите.** В `/var/www/webshare/tmp/zip/`, изтриват се след час. Същата непроменена папка не се архивира втори път.
- **Компресия.** Големите и вече компресираните файлове се записват без компресия. Папка от 6,7 GB се архивира за 12 s.
- **Поправени стари бъгове.**
  - Имената в архива губеха първите 4 символа заради симлинка `src/files`.
  - Прекъснато сваляне оставяше архива в `/tmp`. Намерен е такъв от 6,8 GB и е изтрит.
