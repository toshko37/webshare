# Квоти по потребител (F1)

| | |
|---|---|
| Код | `src/quota.php` |
| Настройки | Settings → Storage Quotas: квота по подразбиране и стойност за всеки потребител, в MB. 0 = без лимит, празно = по подразбиране. |
| Тест | `php tests/quota-unit.php`, 13 проверки. На живо са проверени качване като admin, качване през API и Public. |

- **На кого е квотата.** На собственика на папката (`files/<потребител>/…`), независимо кой качва:
  - самият потребител;
  - admin;
  - API ключ;
  - качване в споделена папка;
  - анонимно качване към `/u/<потребител>`;
  - сваляне от URL.
- **Какво не се брои.** Public (там важат лимитите на Upload Guard) и кошчето (D-028).
- **Кога се проверява.** Преди записа, по размера на файла. При сваляне от URL размерът се знае едва след свалянето, затова проверката е тогава.
- **Отказ.** Отговорът е HTTP 413 със съобщение. Програмата за качване в админ панела вече показва грешките от сървъра; преди тихо ги пропускаше.
- **Намалена квота** под заетото място не трие нищо. Новите качвания се отказват, докато не се освободи място.
- **Видимост.** Лента със заетото място има в Files (за папката, която се гледа) и в Settings.
